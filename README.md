# STEAL THE WIND 응원법 연습

TOMORROW X TOGETHER 월드투어 「STEAL THE WIND」 서울·일본 공연 준비용 팬 페이지.

- **투어**: 서울(KSPO DOME) · 일본 돔 4개 도시 일정, 내가 가는 날 표시 + D-day
- **세트리스트**: 지난 투어 「ACT : TOMORROW」 서울(2025.08)·도쿄돔(2026.01) 세트리스트, 곡별 아이콘
  (👑 타이틀 · 💿 수록곡 · 🎤 솔로 · 🇯🇵 일본곡/일본어 ver. · ✨ 신곡 · 🔁 지난 투어 · 📣 응원법 준비됨)
- **응원법 연습**: 유튜브 링크나 내 음악 파일로 노래를 틀고, 붙여넣은 응원법을 노래방처럼 따라가며 연습.
  탭으로 싱크 맞추기, 한 줄 반복, 느리게 재생, 가리기(암기 테스트) 모드.

## 실행
```
npm install
npm run dev
```

## 데이터 고치기
- 공연 일정: `src/data/tour.js`
- 곡 정보: `src/data/songs.js`
- 세트리스트: `src/data/setlists.js`
- 기본 응원법(모든 기기에서 보이게): `src/data/cheers.js`
